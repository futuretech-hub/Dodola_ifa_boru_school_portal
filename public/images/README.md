# Landing-page images

Upload these two files to this folder in GitHub:

- `school-logo.png` — the circular Ifa Boru school emblem. A square PNG with a transparent or clean background works best.
- `school-building.jpg` — the school/campus background image. A landscape image around 1600×900 or wider works best.

The landing page already references these paths:

```text
/public/images/school-logo.png
/public/images/school-building.jpg
```

Do not rename the files unless you also update `app/globals.css` and `app/page.tsx`.
